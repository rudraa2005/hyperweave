THEORY
Conditional model generation
The preference vector λ weights task quality, shift robustness, and inference cost. Context bins capture link load and alert rate. The hypernetwork maps neuron embeddings, λ, and context to functional-neuron parameters.
IMPLEMENTATION
Measured deployment path
The UI bakes generated parameters without retraining, removes closed gates, quantizes to int8, and compares the C kernel with the Python reference. Detection uses a threshold calibrated on A-val; outcomes are written to the local registry.
RESEARCH LIMITS
Evidence stays explicit
Results use an endpoint-group alternate split. Timing is unpinned, C1–C4 remain inconclusive, the agent run is scripted, and response actions are simulations. Open Scoreboard and Limits for the full evidence.
